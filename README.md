# 🕹️ Game Shop - A sua loja de games!

Este é um projeto de um site fictício de uma loja de games, desenvolvido para fins de aprendizado.

## 📖 Sobre o Projeto

O **Game Shop** é uma página estática desenvolvida para simular um site de vendas de jogos e consoles. O objetivo é praticar a estruturação de páginas HTML e o uso de CSS para estilização.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** → Estrutura da página
- **CSS3** → Estilização e layout
- **Google Fonts** → Fonte personalizada
- **Git/GitHub** → Controle de versão e hospedagem
